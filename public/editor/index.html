博客编辑器

1手机浏览器打开 github.com/settings/tokens → Generate new token（选 Fine-grained）
2Repository access 选 “Only select repositories” 勾选 myblog；Permissions 里把 Contents 设为 “Read and write”
3有效期建议 90 天，生成后复制，粘贴到上面保存
token 仅保存在本机浏览器，可随时在设置中清除
